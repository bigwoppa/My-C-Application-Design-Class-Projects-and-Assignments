# C++ Book Class

## About

This program demonstrates how classes and objects work in C++. It creates a `Book` class that stores information about a book.

## Features

- Private data members
- Constructor
- Getter and setter
- Member functions
- Two `Book` objects
- Displays each book’s information

## Class Information

Each book contains:

- Title
- Author
- Price

The program can also apply a discount and update a book’s price.

## How to Run

1. Save the code as `main.cpp`.
2. Compile the program:

```bash
g++ main.cpp -o book_program
```

3. Run the program:

```bash
./book_program
```
