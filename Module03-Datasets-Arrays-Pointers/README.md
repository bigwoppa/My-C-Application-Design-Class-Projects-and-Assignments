# Record Manager

A C++ console application that allows users to add, view, search, delete, and clear records stored in a CSV file.

## Features

- Personalized welcome screen
- Displays application information using multiple variable types
- Adds names and ages to `records.csv`
- Views and searches saved records
- Deletes individual records
- Clears all saved records
- Validates menu input

## Concepts Demonstrated

- `cout` and `cin`
- Variables and data types
- Functions
- Loops and switch statements
- File handling
- Vectors and string streams

## Running the Program

Compile and run `main.cpp` using a C++ compiler such as G++.

```bash
g++ main.cpp -o main
./main
```
